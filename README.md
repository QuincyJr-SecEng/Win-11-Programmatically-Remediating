<h1>🛡️ Windows 11 Authenticated Vulnerability Scanning & Scripted Remediation</h1>

<p>
This project demonstrates hands-on experience performing <strong>authenticated vulnerability scanning</strong> and <strong>scripted remediation</strong> on a Windows 11 virtual machine using <strong>Tenable Vulnerability Management</strong>. The lab highlights how credentialed scans uncover deep system misconfigurations and how PowerShell-driven remediation measurably reduces risk.
</p>

<h2>🎯 Project Objective</h2>
<p>
Show how authenticated scanning and repeatable remediation workflows can identify, fix, and validate the resolution of common Windows 11 vulnerabilities—mirroring real SOC and Vulnerability Management operations.
</p>

<h2>🧰 Tools & Technologies</h2>
<ul>
  <li>Windows 11 Virtual Machine</li>
  <li>Tenable Vulnerability Management</li>
  <li>Authenticated (Credentialed) Scanning</li>
  <li>DISA Windows 11 STIG Template</li>
  <li>PowerShell & Windows Registry</li>
</ul>

<h2>⚙️ What This Demonstrates</h2>
<ul>
  <li>Secure provisioning of Windows 11 virtual machines using strong credentials</li>
  <li>Configuration of Windows systems to support authenticated remote scanning</li>
  <li>Use of DISA STIG-based templates for compliance-aligned assessments</li>
  <li>Detection of insecure software, legacy services, and weak cryptographic protocols</li>
  <li>Scripted remediation using PowerShell for consistency and scalability</li>
  <li>Verification of remediation effectiveness through rescanning and comparison</li>
</ul>

<h2>📊 Key Outcomes</h2>
<ul>
  <li>Successfully executed credentialed vulnerability scans against Windows 11</li>
  <li>Identified vulnerabilities including outdated Firefox versions, SMBv1 exposure, and deprecated SSL/TLS protocols</li>
  <li>Remediated findings using PowerShell scripts and batch execution</li>
  <li>Validated measurable risk reduction through post-remediation scan results</li>
</ul>

<h2>🧠 SOC & Vulnerability Management Alignment</h2>
<p>
This project reflects enterprise SOC workflows by combining credentialed scanning, DISA STIG alignment, automated remediation, and verification—core functions of modern Vulnerability Management programs.
</p>

<h2>🔐 Security Best Practices Highlighted</h2>
<ul>
  <li>Avoidance of default or weak credentials</li>
  <li>Secure remote administrative access configuration</li>
  <li>Disabling legacy protocols and insecure cryptography</li>
  <li>Automated remediation for repeatability and scale</li>
</ul>

<h2>🧹 Cleanup & Operational Hygiene</h2>
<p>
After validating remediation success, all testing artifacts—including scans, scripts, and the Windows 11 virtual machine—were safely deleted to maintain secure lab practices and cost control.
</p>
